# HTML/CSS Recap

### HTML
- **Structure of web pages.**
- **Tags**: `<html>`, `<head>`, `<body>`, etc.
- **Common elements**: headers, paragraphs, links, images.

### CSS
- **Styling web pages.**
- **Selectors**: class, id, element selection.
- **Box Model**: margin, border, padding, content.

### Example:
```html
<div class="container">
    <h1>Welcome</h1>
    <p>This is an example of a simple HTML structure.</p>
</div>
```
